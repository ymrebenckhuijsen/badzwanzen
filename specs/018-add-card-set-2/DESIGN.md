# Design Addendum: 018-add-card-set-2

**Status**: No UI Impact

This feature only adds new card data (Naam/Spel/Virus/Iedereen instruction texts and matching
`liftText` end-messages) to the existing, already-approved Badzwanzen card set. It introduces no
new screens or components and changes no existing UI — the card, session, and virus-list screens
already render arbitrary card content unchanged. Same determination as feature 014
(`014-add-card-set`).
